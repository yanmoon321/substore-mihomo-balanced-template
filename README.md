# Sub-Store Mihomo Balanced 模板

个人自用的 Mihomo 分流配置模板，供 Sub-Store「文件 → mihomo 配置」作为远程配置来源。

`balanced.yaml` 只有一个无效的占位节点 `SUBSTORE_DYNAMIC_NODE_PLACEHOLDER`，不包含真实订阅、节点或密钥。它必须经过 Sub-Store 注入已有订阅节点后才能作为最终配置使用。

## 在 Sub-Store 中使用

1. 将文件来源设为「远程」，填入本仓库 `balanced.yaml` 的 Raw 地址；来源模式选择完整配置（`config`）。
2. 移除原来负责注入整份本地 YAML 模板的操作，避免它覆盖远程文件。
3. 保留「从订阅添加节点」操作，选择自己现有的订阅或组合订阅，并将节点列表设为替换模板占位节点。
4. 保留末尾的策略组占位符替换脚本，让各策略组引用实际生成的节点名称。
5. 在 Sub-Store 生成结果中确认节点数量、13 个策略组、规则顺序及无占位符，再更新客户端订阅。

仓库更新后，Sub-Store 需要再次获取并生成文件，客户端也需要刷新订阅；远程获取可能受缓存影响。

不要将 Sub-Store 生成后的配置或实际订阅链接提交到此仓库。
